## 1. Виджет «Стек кафедры» (`stack-widget.html`)

### Что внутри
- **9 кластеров**: Web, .NET/C#, Java/Spring, Python/AI, Базы данных, Мобильная, Кибербезопасность, Встраиваемые/IoT, UI/UX.
- Каждый раскрывается тапом/кликом → 4 раздела: **Дисциплины** (из сайта), **Проекты студентов**, **Партнёры**, **Куда идут выпускники**.
- Долгое нажатие (500 мс) или клик по ▼ → модалка с QR-кодом (placeholder, замените на реальные ссылки на GitHub/Telegram).
- Адаптивен: 1920 / 2560 / 3840 px (медиа-квери как в вашем `index.html`).
- Работает офлайн — просто откройте файл в браузере на стенде.

### Как кастомизировать
1. Откройте `stack-widget.html` в редакторе.
2. Найдите массив `clusters` (в `<script>`).
3. Правите `disciplines`, `projects`, `partners`, `graduates` под актуальные данные.
4. QR-коды: замените SVG в `.qr-placeholder` на настоящий QR (например, через `qrcode.js` или вставьте `<img src="...">`).

### Запуск на стенде
```bash
# Просто откройте в браузере на 4K-мониторе
# Firefox/Chrome — F11 для фуллскрина
# Файл полностью автономен, интернет не нужен
```

## 2. Telegram-бот (`bot.py`)

### Возможности
- Абитуриент выбирает категорию → пишет вопрос → уходит в нужный чат.
- Ответственный нажимает «✅ Ответить» → пишет ответ → бот доставляет абитуриенту.
- Категории: **Учёба** (студенты-волонтёры), **Трудоустройство** (HR/партнёры), **Проекты/НИР** (преподаватели), **Зав. кафедрой** (зав.каф.).

### Настройка (переменные окружения)
```bash
export BOT_TOKEN="123456:ABC-DEF..."           # от @BotFather
export CHAT_STUDENTS="-1001234567890"          # группа студентов-волонтёров
export CHAT_TEACHERS="-1001234567891"          # чат преподавателей/зав.каф.
export CHAT_CAREER="-1001234567892"            # чат HR/карьеры
```

### Запуск
```bash
pip install python-telegram-bot==20.7
python bot.py
```

### Как добавить бота в чаты
1. Создайте группы в Telegram.
2. Добавьте бота в каждую группу.
3. Сделайте бота админом (чтобы он мог читать сообщения).
4. Узнайте `chat_id`: перешлите любое сообщение из группы боту `@userinfobot` или используйте `@RawDataBot`.
